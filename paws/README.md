# PAWS 平面図 — ドッグサロン兼カフェ（客席3案）

愛媛県西条市の PAWS 計画のうち、**サロン兼カフェ棟**の客席バリエーション。  
**部屋配置は添付元図のトポロジーを踏襲**し、横幅のみ 11.5 m に再配分しています。

## 共通条件

| 項目 | 内容 |
|------|------|
| 建築幅（画像の横） | **11,500 mm（11.5 m）** ※元図 14,560 mm から再配分 |
| 建築奥行（画像の縦） | **12,740 mm**（元図据置） |
| 入口 | 風除室①② — 既存位置を維持 |
| 厨房 | **10.0帖（16.2 ㎡）** — 左上 |
| 保護猫エリア | **約4.1帖** — 上部中央、犬ゾーンと分離 |
| スタッフルーム / 洗濯室 | 各約4.1帖 — 右上に横並び |
| シャンプー / トリミング | 各 **5.1帖** — 右翼に縦積み |
| 屋外デッキ | 西側（建物左外） |

## 横方向の再配分（mm）

`4450 + 910 + 1820 + 680 + 3640 = 11500`

## 縦方向（据置・mm）

`3640 + 910 + 2275 + 2275 + 3640 = 12740`

## 再生成

```bash
cd plans
python3 generate_floorplans.py
python3 -c "from pathlib import Path; import cairosvg
for p in Path('.').glob('paws-cafe-*.svg'):
    cairosvg.svg2png(url=str(p), write_to=str(p.with_suffix('.png')), scale=2.4)"
```
